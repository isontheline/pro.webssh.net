# Contributing

Thank you for taking the time to contribute to WebSSH.

This repository accepts pull requests for the content it publishes: the
[documentation](documentation), the [Snippets Library](snippets/README.md) and the
[State Bar Library](statebar/README.md). Each library has its own guide describing the expected
layout and the automated checks; please read it before opening a pull request.

## Acceptance of contributions

WebSSH is maintained by a single person, who remains responsible for everything that ships to
users. For that reason:

- **Merging is at the maintainer's sole discretion.** Opening a pull request does not create any
  obligation to review, merge or keep it open, and passing the automated checks is not an
  acceptance.
- **A pull request may be declined for any reason**, including its scope, its maintenance cost,
  its fit with the project's direction, or the authorship, co-authorship and attribution recorded
  in its commits and description. A reason will be given whenever practical, but none is owed.
- **Commits may be squashed, reworded or amended before merging.** This includes removing
  trailers and metadata such as `Co-Authored-By` lines, tool or session links and generated
  footers. The contributor who opened the pull request stays credited as the author.

## What makes a pull request easy to accept

- One topic per pull request, with a description of what was tested and what was not.
- Commits authored by you, under your own GitHub identity, with no tool attribution, promotional
  footer or session link in the commit message or the pull request description.
- You have read and understood every line you submit, and you are able to maintain it: you are
  the one listed in `maintainers`, whatever tools helped you write it.
- By submitting a contribution, you confirm that you have the right to do so and that it is
  provided under the [license](LICENSE) of this repository.

A declined pull request is never a judgement on its author. Suggestions are always welcome as
[issues](https://github.com/isontheline/pro.webssh.net/issues) too.
