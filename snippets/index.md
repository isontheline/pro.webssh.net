# WebSSH Curated Snippets

Hand-curated shell snippets for the [WebSSH](https://webssh.net) app.
Browse them in-app: **Snippets → ••• → WebSSH Library**.

Each collection below is a folder holding a `webssh.json` manifest and one file per snippet.
Want to share yours? See [CONTRIBUTING](README.md).
