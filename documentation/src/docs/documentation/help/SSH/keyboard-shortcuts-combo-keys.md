# Keyboard Shortcuts

!!! tip "Shortcuts / Combo Keys"
    Your favorite external keyboard doesn't have all useful keys? 

    Don't worry you can use combo keys listed on this page.

| Real Key | WebSSH' Combo Keys |
| --- | --- |
| Esc | Ctrl + Alt + Shift + E |

## Shift + Enter
Since WebSSH 33.4, `Shift + Enter` sends a line feed (the same as `Ctrl + J`) instead of a plain `Enter`: a new line in the prompt of Claude Code and other coding agents. See [Shift + Enter for a New Line](../howtos/SSH/shift-enter-new-line.md).
