# WebSSH : SSH, SFTP and Port Forwarding client for iPhone, iPad and Mac
## About WebSSH
WebSSH is an "awesome" iOS / macOS SSH, SFTP and Port Forwarding client since 2012!

It is a native app for **iPhone**, **iPad** and **Mac** : SSH terminal, SFTP file manager, Telnet, [Port Forwarding](/documentation/help/networking/port-forwarding/) and sysadmin tools in a single toolbox.

* **Free** : every feature is available, with one saved connection
* **No subscription** : [WebSSH PRO](/documentation/pricing/) is a one-time purchase, valid on all your devices
* **No account, no data collection** : your connections and keys stay on your device

## Installation
1. Launch the App Store on your iPhone, iPad or Mac
2. Search for "WebSSH - SysAdmin Tools"
3. Install it, it's [freemium](/documentation/pricing/)!

Alternately if you don't find it, use this link to the App Store : [download WebSSH](https://apps.apple.com/us/app/webssh-ssh-client/id497714887)

## What about the name?
The name sounds weird? Think twice! WebSSH is a NATIVE and LOCAL SysAdmin Toolbox with Privacy and Security in mind which ensure that no data will leave your device outside your own secure servers.

As everybody knows, the "SSH" part means Secure Shell. But what about the "Web" part?

Just because WebSSH terminal rendering engine is based on [Xterm.js](https://xtermjs.org/), a JS library running on your own device! :)

??? info "Looking for SSH in a web browser?"
    WebSSH is not a website or an online SSH service : it's an app you install on your iPhone, iPad or Mac. Connections go straight from your device to your server, nothing in between.
